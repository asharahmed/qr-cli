Made for the shell.

        
One argument in, one code out. Everything else is a flag, and every flag does one thing.

      

      
    
        
  • 
          
          Terminal native
          Unicode half-blocks render a crisp code in any shell, including over SSH. Add -l for a larger one.
        
    • 
        
  • 
          
          PNG and SVG
          Name the output file and the format follows. Set the size and quiet zone for print.
        
    • 
        
  • 
          
          Pipes and files
          Reads stdin and heredocs, or a file with -f. Drops into scripts, CI jobs and cron.
        
    • 
        
  • 
          
          Light terminals
          -i inverts the modules so the code still scans on a white background.
        
    •

Small commands.

        
Pass text, get a code. These cover most of what people reach for.

      

      
    
        
  • 
          Print a code
          $ qr "https://example.com"
          
        
    • 
        
  • 
          Light terminal
          $ qr "Hello World" -i
          
        
    • 
        
  • 
          Larger modules
          $ qr "Hello World" -l
          
        
    • 
        
  • 
          Save a PNG
          $ qr "https://example.com" -o qrcode.png
          
        
    • 
        
  • 
          From a pipe
          $ echo "secret message" | qr
          
        
    • 
      

    


    

      

        
No browser, no tracking.

      

      
    
        
  • Works offlineCodes are encoded on your machine. There's no network call, account or rate limit.
    • 
        
  • Nothing to leakWhat you encode stays in your shell history, not on someone else's QR website with ads.
    • 
        
  • Two dependenciescommander and qrcode, both MIT. A code renders in well under a second.
